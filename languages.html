Languages and tools

Many languages can produce WebAssembly. A compiler turns source code into a .wasm file, an optimiser can shrink it, and JavaScript loads it.

Languages

Common ways to target WebAssembly
LanguageCommon toolchainNotes
C and C++Emscripten, or clang with a wasm32 targetThe largest body of ported code. SQLite, for example, has an official Wasm build.
RustBuilt-in wasm32 targets, wasm-bindgen, wasm-packNo garbage collector, so output can be small.
AssemblyScriptasc compilerTypeScript-like syntax designed for Wasm.
GoStandard compiler (GOOS=js GOARCH=wasm), or TinyGoThe standard output carries the Go runtime and is larger. TinyGo produces smaller files.
ZigBuilt-in wasm32 targetsCompiles to Wasm without extra tooling.
C#Blazor WebAssemblyRuns the .NET runtime inside Wasm.
PythonPyodideCPython compiled to Wasm, so Python runs in the browser.
Kotlin and DartKotlin/Wasm, Dart's Wasm compilerUse WebAssembly's garbage collection support.

Tools for Wasm itself

WABT
The WebAssembly Binary Toolkit. wat2wasm turns text into binary and wasm2wat goes back. The demo module on this site was built with it.
Binaryen
An optimiser and compiler toolkit. Its wasm-opt tool makes modules smaller and faster.
Browser DevTools
Chrome, Firefox and Safari can show a module's text form and step through it in the debugger.
