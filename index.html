WebAssembly, explained

WebAssembly, or Wasm, is a compact binary format that browsers run at near-native speed. You write code in a language such as C, C++ or Rust, compile it once, and run it next to your JavaScript.

00 61 73 6d 01 00 00 00

The first eight bytes of every .wasm file: the magic number \0asm, then format version 1.

Try it in your browser Read what it is

Four ideas behind it

Efficient and fast
A compact binary format that loads quickly and is designed to run at close to native speed.
Safe
Code runs in a memory-safe sandbox. On the web it follows the browser's same-origin and permission rules.
Open and debuggable
There is a human-readable text format for reading, testing and hand-writing modules. The Try it page shows one.
Part of the open web platform
Standardised at the W3C, supported by every major browser, and able to call JavaScript and Web APIs.
